FAQ

Is there an official Google Trends API?

Google opened an alpha API to a small group of testers only. This API returns the same data today, with no application or quota.

What is the best pytrends alternative?

pytrends was archived in 2024 and often fails with HTTP 429 errors. This hosted API covers the same functions and handles blocking, retries and proxies for you.

Can I compare more than 5 keywords?

Yes. Set keywordRanking: true: terms are queried in batches sharing an anchor term and rescaled onto one 0-100 scale.

Does Google Trends give search volume?

Explore data is a relative 0-100 index. Trending Now items include the approximate search volume shown by Google, and this API returns it.
